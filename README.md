# 💼 Company Salary Analytics & AI Prediction System

An end-to-end Data Analytics and Machine Learning project that simulates real-world salary data, performs exploratory analysis, builds a complete ETL pipeline, and deploys an AI-powered salary prediction dashboard.

This project covers the full data science lifecycle — from data generation to an interactive AI application.

---

## 🚀 Project Features

✅ Realistic salary data generation using Python  
✅ PostgreSQL database for structured storage  
✅ ETL pipeline using SQLAlchemy and Pandas  
✅ Exploratory Data Analysis (EDA) with Seaborn  
✅ Smart data cleaning and preprocessing  
✅ Machine Learning models (Linear Regression & Random Forest)  
✅ Explainable AI using feature importance  
✅ Real-time salary prediction system  
✅ Interactive Streamlit dashboard
